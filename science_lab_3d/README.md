# LABVERSE — 3D 과학실험실 프로토타입

## Windows에서 가장 쉽게 실행하기

1. ZIP 파일을 완전히 압축 해제해.
2. 압축을 푼 `science_lab_3d` 폴더 안에서 `실행하기.bat`을 더블클릭해. (한 번만 실행하면 서버와 브라우저가 자동으로 열려.)
3. 검은색 터미널 창을 닫지 말고, 브라우저가 열리면 `http://localhost:8000`으로 접속해.
4. 종료할 때는 터미널 창을 선택하고 `Ctrl + C`를 누르면 돼.

`localhost:8000`에서 "연결을 거부했습니다"가 뜨면 서버가 켜지지 않았거나 터미널 창이 닫힌 경우가 많아. 주소를 입력하기 전에 `실행하기.bat`을 먼저 실행해 줘.

## 수동 실행 방법

Python이 설치되어 있다면 이 폴더에서 명령 프롬프트/터미널을 열고 실행해:

```bash
python -m http.server 8000
```

그 터미널 창을 계속 열어 둔 상태에서 브라우저로 `http://localhost:8000`에 접속해.

만약 `python` 명령이 인식되지 않으면 Windows에서 다음 명령을 시도해:

```bash
py -m http.server 8000
```

## 중요한 실행 주의

- `app.js`는 단독으로 열거나 코드 편집기의 미리보기/시각화 기능에 붙여 넣는 파일이 아니야. `index.html`이 `<script type="module" src="app.js"></script>`로 불러오는 모듈이야.
- `index.html`, `style.css`, `app.js`는 반드시 같은 폴더에 있어야 해.
- Three.js와 OrbitControls를 CDN에서 가져오기 때문에 인터넷 연결이 필요해.
- 포트 8000을 이미 다른 프로그램이 사용 중이면 `python -m http.server 8001`로 실행하고 `http://localhost:8001`로 접속해.

## 현재 구현된 기능

- Three.js 기반 3D 실험대, 비커, 시험관, 스탠드, 가열 장치
- 카메라 회전·확대/축소, 시점 초기화, 비커 라벨 표시 전환
- 화학·물리·생물·지구과학 재료 목록과 검색/분류
- 재료 추가 및 용기 비우기
- 비커 안의 액체와 토양 입자층을 개별적으로 제거하는 `빼기` 버튼
- 온도·농도·교반 조건 조절
- 일부 등록된 조합의 교육용 결과 모델: 물+소금, 식초+베이킹소다, 지시약, 씨앗+물, 토양+물, 자석+철, 스프링, 렌즈 등
- 관찰 기록, 실험 시간, 교육용 질량 보존 표시
- 반응 규칙이 없는 조합은 결과를 꾸며내지 않고 미등록 상태로 안내

## 중요한 한계

현재는 학습용 프로토타입이야. 모든 화학 반응을 자동 예측하지 않으며, 농도·온도·반응 속도는 일부 시각 효과와 설명에만 반영돼. 원자 수준의 반응 계산, 정확한 열역학, 정량적인 질량/에너지 수지, 실제 생물 성장, 정밀 광학·자기장 계산은 아직 구현되지 않았어. 질량 보존 수치는 교육용 단순 모델 값이며 실험 측정값이 아니야.


## 재료 유형별 표현 (업데이트)

- 액체(물, 식초, 지시약)는 비커 안의 액체로 표현합니다.
- 소금·베이킹소다는 작은 입자 집합으로 표현합니다.
- 토양은 실험대 위의 시료가 아니라 비커 바닥에 쌓이는 입자층으로 표현하며, 비커 내용물 목록에서 개별 제거할 수 있습니다.
- 철 조각은 금속 덩어리, 자석은 극이 다른 말굽 자석, 렌즈는 투명한 볼록 렌즈 형태로 표현합니다.
- 스프링은 코일 형태, 씨앗은 타원형 종자, 잎 표본은 납작한 잎, 토양은 여러 크기의 입자가 모인 시료로 표현합니다.
- 질량 표시에는 비커 속 액체뿐 아니라 실험대 위 고체 시료도 포함되므로, 밀폐 용기 내부의 측정 질량과 혼동하지 않도록 표기합니다.

이 단계의 3D 표현은 교육용 시각 모델입니다. 자석의 힘, 렌즈의 광선 추적, 스프링의 실제 변형, 토양의 침투·침식, 생물의 성장 등은 각각 별도 물리 모델로 추가해야 합니다.


## 고체 시료 이동

- 물, 식초, 지시약은 액체로 취급해 비커에 남아 있어.
- 그 밖의 고체 시료는 3D 실험대에서 마우스로 직접 드래그해 위치를 옮길 수 있어.
- 빈 공간을 드래그하면 카메라가 회전하고, 마우스 휠로 확대/축소해.
- 시료 이동은 현재 실험대 평면 위의 위치 이동이며, 중력·충돌·실제 물리 힘까지 계산하는 기능은 아직 아니야.
